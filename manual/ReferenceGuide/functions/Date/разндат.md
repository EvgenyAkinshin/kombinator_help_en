# разндат

Функция `разндат` возвращает разницу между двумя датами в днях.

Функция пригодится, когда необходимо определить продолжительность периода между датами, например количество дней между началом и окончанием события или документа.

## Синтаксис

```text
разндат(начальнаяДата, конечнаяДата)
```

**Параметры:**

- `начальнаяДата` — дата, от которой рассчитывается разница. Обязательный параметр;
- `конечнаяДата` — дата, до которой рассчитывается разница. Обязательный параметр.

В качестве параметров можно использовать:

- значения полей;
- результаты других функций;
- выражения.

## Возвращаемое значение

Функция возвращает числовое значение — разницу между датами в днях.

Знак результата зависит от порядка дат:

- если `конечнаяДата` позже `начальнаяДата`, результат положительный;
- если `конечнаяДата` раньше `начальнаяДата`, результат отрицательный;
- если даты совпадают, результат равен `0`.

## Особенности

Порядок параметров влияет на результат.

Например:

```text
разндат("31.03.2025", "04.06.2025")
```

Результат:

```text
65
```

Если поменять даты местами:

```text
разндат("04.06.2025", "31.03.2025")
```

Результат:

```text
-65
```

---

Если даты совпадают, функция возвращает `0`:

```text
разндат("15.04.2025", "15.04.2025")
```

Результат:

```text
0
```

---

Функция принимает значения даты со временем.

Например:

```text
разндат(
    "15.04.2025 12:00:00",
    "16.04.2025 00:00:00"
)
```

Результат:

```text
0
```

> В данном примере разница между значениями составляет менее суток, поэтому функция возвращает `0`.

## Примеры

**Расчёт количества дней между датами**

```text
разндат("15.04.2025", "16.04.2025")
```

Результат:

```text
1
```

---

**Использование результатов других функций**

В качестве параметров можно передавать даты, сформированные другими функциями:

```text
разндат(
    дата(15, 4, 2025),
    дата(20, 4, 2025)
)
```

Результат:

```text
5
```

## Ошибки

Функция возвращает ошибку, если один из обязательных параметров не содержит значения.

Ошибка возникает, если не заполнено:

- `начальнаяДата`;
- `конечнаяДата`.

## Связь с другими функциями

Функцию `разндат` можно использовать совместно с другими функциями для работы с датами.

Например, можно рассчитать количество дней между сегодняшней датой и датой, смещённой на один месяц:

```text
разндат(
    сегодня(),
    датамес(сегодня(), 1)
)
```

В проверенном примере результат:

```text
30
```

Даты для расчёта также можно сформировать с помощью функции `дата`:

```text
разндат(
    дата(15, 4, 2025),
    дата(20, 4, 2025)
)
```

Результат:

```text
5
```

Таким образом, `разндат` можно использовать как часть более сложного выражения, когда начальная или конечная дата определяется другой функцией.
