# сегодня

Функция `сегодня` возвращает текущую дату на момент формирования документа.

Функция пригодится, когда в документ необходимо автоматически подставить актуальную дату или использовать её в расчётах.

## Синтаксис

```text
сегодня()
```

**Параметры:**

Функция не принимает параметров.

## Возвращаемое значение

Функция возвращает текущую дату со временем `00:00:00`.

Например, если документ формируется 2 сентября 2026 года:

```text
сегодня()
```

Результат:

```text
02.09.2026 00:00:00
```

## Особенности

Значение функции определяется **в момент формирования документа**.

Поэтому при формировании одного и того же шаблона в разные дни функция `сегодня()` возвращает соответствующую дату формирования.



## Примеры

**Использование текущей даты в расчёте**

Текущую дату можно использовать как исходное значение для других функций.

Например:

```text
датамес(сегодня(), 1)
```

Если документ формируется 2 сентября 2026 года, результат:

```text
02.10.2026 00:00:00
```

---

**Расчёт разницы между датами**

Функцию можно использовать для определения количества дней между текущей и другой датой:

```text
разндат(сегодня(), конечнаяДата)
```

Результат зависит от значения `конечнаяДата`.

## Связь с другими функциями

Результат функции `сегодня` можно использовать в других функциях для работы с датами.

Например, текущую дату можно сразу вывести в нужном формате:

```text
форматДаты(
    сегодня(),
    ФорматДаты.ДатаКратко
)
```

Если документ формируется 2 сентября 2026 года, результат:

```text
02.09.2026
```

Для собственного формата отображения можно использовать функцию `форматДатыПоМаске`:

```text
форматДатыПоМаске(
    сегодня(),
    "dd MMMM yyyy"
)
```

При русской локали результат:

```text
02 сентября 2026
```

Функцию `сегодня` также можно использовать совместно с функциями расчёта дат, например `датамес`, `начмесяца`, `конмесяца` и `разндат`.
