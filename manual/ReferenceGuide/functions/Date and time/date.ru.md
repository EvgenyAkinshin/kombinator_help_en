# дата

Функция `дата` формирует дату из отдельно заданных дня, месяца и года.

Функция пригодится, когда части даты хранятся в разных полях или вычисляются непосредственно в выражении.

## Синтаксис

```text
дата(день, месяц, год)
```

**Параметры:**

- `день` — день месяца. Обязательный параметр. Числовое значение от `1` до `31`;
- `месяц` — номер месяца. Обязательный параметр. Числовое значение от `1` до `12`;
- `год` — год. Обязательный параметр. Указывается числом, например `2026`.

Параметры указываются в порядке: **день, месяц, год**.

В качестве параметров можно использовать:

- числа;
- значения числовых полей;
- числовые выражения.

## Возвращаемое значение

Функция возвращает значение даты.

Поскольку часы, минуты и секунды в функции не задаются, время устанавливается как `00:00:00`.

Например:

```text
дата(12, 8, 2026)
```

Результат:

```text
12.08.2026 00:00:00
```

## Особенности

Переданные значения должны образовывать существующую календарную дату.

Значение дня может находиться в диапазоне от `1` до `31`, но допустимое максимальное значение зависит от выбранных месяца и года.

При передаче дробного числового значения функция преобразует его при формировании даты.

Например:

```text
дата(1.5, 5, 2026)
```

Результат:

```text
02.05.2026 00:00:00
```

## Примеры

**Значения из полей**

Если поля содержат:

- `день` = `5`;
- `месяц` = `9`;
- `год` = `2026`;

то выражение:

```text
дата(день, месяц, год)
```

вернёт:

```text
05.09.2026 00:00:00
```

---

**Использование выражения**

В параметрах функции можно выполнять вычисления.

Если поля содержат:

- `день` = `5`;
- `месяц` = `9`;
- `год` = `2026`;

то выражение:

```text
дата(день + 1, месяц, год)
```

вернёт:

```text
06.09.2026 00:00:00
```

## Ошибки

Функция возвращает ошибку, если из переданных значений невозможно сформировать дату.

Например:

```text
дата(31, 2, 2026)
```

вернёт ошибку, поскольку в феврале 2026 года нет 31-го дня.

Ошибка также возникает, если:

- день равен `0`;
- номер месяца больше `12`;
- указан день, которого нет в выбранном месяце и году;
- один из обязательных параметров не содержит значения.

Например:

```text
дата(29, 2, 2025)
```

вернёт ошибку, поскольку в 2025 году нет 29 февраля.

## Связь с другими функциями

Функция `дата` может использоваться совместно с другими функциями для работы с датами.

Сформированное значение можно:

- разобрать на отдельные части с помощью функций `день`, `месяц` и `год`;
- использовать для получения календарных данных, например дня недели или номера недели;
- передать в функции форматирования даты.

Функцию `дата` также можно использовать для формирования новой даты на основе существующей.

Например:

```text
дата(день(исходнаяДата), месяц(исходнаяДата), год(исходнаяДата) + 1)
```

Такое выражение сохраняет день и месяц исходной даты, а год увеличивает на `1`.

Сформированную дату можно сразу передать в функцию форматирования:

```text
форматДаты(дата(5, 9, 2026), ФорматДаты.ДатаКратко)
```

Результат:

```text
05.09.2026
```

Для собственного формата отображения можно использовать функцию `форматДатыПоМаске`:

```text
форматДатыПоМаске(дата(5, 9, 2026), "yyyy-MM-dd")
```

Результат:

```text
2026-09-05
```

Таким образом, функцию `дата` можно использовать как часть более сложного выражения: сначала сформировать или изменить дату, а затем получить из неё нужные данные или изменить формат отображения.
