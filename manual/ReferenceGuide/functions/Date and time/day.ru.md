# день

Функция `день` возвращает день месяца из указанной даты.

Функция пригодится, когда день необходимо получить отдельно от полного значения даты и использовать в документе или выражении.

## Синтаксис

```text
день(дата)
```

**Параметры:**

- `дата` — дата, из которой необходимо получить день месяца. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой;
- результат другой функции, возвращающей дату;
- выражение, результатом которого является дата.

## Возвращаемое значение

Функция возвращает день месяца в виде числа от `1` до `31`.

Например:

```text
день("11.08.2026")
```

Результат:

```text
11
```

## Примеры

**Получение дня из значения поля**

Если поле `датаДоговора` содержит:

```text
11.08.2026
```

то выражение:

```text
день(датаДоговора)
```

вернёт:

```text
11
```

---

**Получение текущего дня месяца**

Текущий день можно получить из результата функции `сегодня`:

```text
день(сегодня())
```

Если документ формируется 2 сентября 2026 года, результат:

```text
2
```

## Ошибки

Функция возвращает ошибку, если переданное значение не является корректной датой.

Ошибка также возникает, если обязательный параметр не содержит значения.

## Связь с другими функциями

Функцию `день` можно использовать совместно с другими функциями для работы с датами.

Например, из существующей даты можно получить её отдельные части и сформировать новое значение:

```text
дата(
    день(исходнаяДата),
    месяц(исходнаяДата),
    год(исходнаяДата) + 1
)
```

Такое выражение сохраняет день и месяц исходной даты, а год увеличивает на `1`.

День месяца также можно получить из даты, рассчитанной другой функцией:

```text
день(смещдат(исходнаяДата, 10))
```

В этом случае функция `смещдат` сначала рассчитывает новую дату, а `день` возвращает день месяца из полученного значения.
