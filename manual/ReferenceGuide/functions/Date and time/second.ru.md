# секунды

Функция `секунды` возвращает значение секунд из даты и времени или значения времени.

Функция пригодится, когда секунды необходимо получить отдельно и использовать в документе или выражении.

## Синтаксис

```text
секунды(значение)
```

**Параметры:**

- `значение` — дата и время или время, из которого необходимо получить секунды. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой и временем или временем;
- текстовое значение с датой и временем или временем в корректном формате;
- результат другой функции;
- выражение, результат которого может быть обработан как дата или время.

Например, функция может обработать:

```text
03.09.2026 15:53:21
```

или:

```text
15:53:21
```

## Возвращаемое значение

Функция возвращает значение секунд в виде числа от `0` до `59`.

Например:

```text
секунды("03.09.2026 15:53:21")
```

Результат:

```text
21
```

## Примеры

**Получение секунд из значения времени**

```text
секунды("15:53:21")
```

Результат:

```text
21
```

---

**Получение секунд из значения поля**

Если поле `времяПодписания` содержит:

```text
15:53:21
```

то выражение:

```text
секунды(времяПодписания)
```

вернёт:

```text
21
```

---

**Получение текущего значения секунд**

```text
секунды(тдата())
```

Например, если текущее время `15:53:21`, функция вернёт:

```text
21
```

## Ошибки

Функция возвращает ошибку, если переданное значение не может быть обработано как дата или время.

Ошибка также возникает, если:

- обязательный параметр не содержит значения;
- передано обычное числовое значение.

## Связь с другими функциями

Функцию `секунды` можно использовать совместно с функциями `час` и `минуты` для получения отдельных частей времени.

Например:

```text
время(
    час(исходноеВремя),
    минуты(исходноеВремя),
    секунды(исходноеВремя)
)
```

Если `исходноеВремя` содержит:

```text
15:53:21
```

выражение сформирует значение времени с теми же часами, минутами и секундами.
