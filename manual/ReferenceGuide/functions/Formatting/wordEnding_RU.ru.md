# Окончание

Функция `окончание` подставляет нужное окончание слова в зависимости от рода и числа значения в текстовом поле.

## Синтаксис

```text
окончание(полеТекста, окончаниеМужРода, окончаниеЖенРода, окончаниеСредРода, окончаниеМножЧисла)
```

**Параметры:**

- `полеТекста` — идентификатор текстового поля, по значению которого определяется род и число;
- `окончаниеМужРода` — окончание для мужского рода;
- `окончаниеЖенРода` — окончание для женского рода;
- `окончаниеСредРода` — окончание для среднего рода;
- `окончаниеМножЧисла` — окончание для множественного числа.

Окончания указываются в двойных кавычках.

Например:

```text
окончание(фио, "ый", "ая", "ое", "ые")
```

| Значение поля | Возвращаемое окончание |
| --- | --- |
| Мужской род | `ый` |
| Женский род | `ая` |
| Средний род | `ое` |
| Множественное число | `ые` |

## Возвращаемое значение

Функция возвращает одно из указанных текстовых окончаний.

Например, если поле `фио` содержит ФИО мужчины:

```text
Иванов Иван Иванович
```

выражение:

```text
окончание(фио, "ый", "ая", "ое", "ые")
```

вернёт:

```text
ый
```

## Примеры

### Обращение по ФИО

Выражение:

```text
"Уважаем" & окончание(фио, "ый", "ая", "ое", "ые")
```

Если поле `фио` содержит:

```text
Иванов Иван Иванович
```

результат:

```text
Уважаемый
```

Если поле `фио` содержит:

```text
Иванова Анна Сергеевна
```

результат:

```text
Уважаемая
```

## Ошибки

Значение, по которому определяется род и число, должно содержать текст, подходящий для морфологического анализа.

Если в нём присутствуют цифры, кавычки или знаки препинания, функция может не определить нужную форму или вернуть ошибку.
