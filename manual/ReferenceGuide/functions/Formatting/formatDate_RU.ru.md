# форматДаты

Функция `форматДаты` изменяет формат отображения даты и времени.

Функция позволяет вывести дату или время целиком, получить отдельные части значения или представить дату прописью.

## Синтаксис

```text
форматДаты(дата, формат)
```

**Параметры:**

- `дата` — значение даты, времени или даты и времени, которое необходимо отформатировать;
- `формат` — формат отображения результата.

## Возвращаемое значение

Функция возвращает текстовое значение в выбранном формате.

Например, если поле `датаДоговора` содержит дату:

```text
01.12.2023
```

выражение:

```text
форматДаты(
    датаДоговора,
    ФорматДаты.ДатаКратко
)
```

вернёт:

```text
01.12.2023
```

## Особенности

Выбранный формат определяет, какая часть исходного значения попадёт в результат.

Например, из значения типа «Дата/Время» можно получить только дату:

```text
форматДаты(
    датаВремя,
    ФорматДаты.ДатаКратко
)
```

только время:

```text
форматДаты(
    датаВремя,
    ФорматДаты.Время
)
```

или отдельную часть даты, например год:

```text
форматДаты(
    датаВремя,
    ФорматДаты.Год
)
```

Если стандартных вариантов недостаточно, для формирования собственного представления даты и времени используйте функцию `форматДатыПоМаске`.

## Примеры

### Дата с кавычками

Выражение:

```text
форматДаты(
    датаДоговора,
    ФорматДаты.ДатаСКавычкамиЕлочки
)
```

вернёт:

```text
«01» декабря 2023 г.
```

### Дата прописью

Выражение:

```text
форматДаты(
    датаДоговора,
    ФорматДаты.ДатаПрописью
)
```

вернёт:

```text
первое декабря две тысячи двадцать третий год
```

### Получение дня недели

Если дата приходится на пятницу, выражение:

```text
форматДаты(
    датаДоговора,
    ФорматДаты.ДеньНедели
)
```

вернёт:

```text
Пятница
```

## Связь с другими функциями

В параметр `дата` можно передавать результат другой функции, если она возвращает значение даты или времени.

Например, функцию `форматДаты` можно использовать вместе с функцией `дата`:

```text
форматДаты(
    дата(1, 12, 2023),
    ФорматДаты.ДатаПолностьюГода
)
```

Результат:

```text
1 декабря 2023 года
```

Сначала функция `дата` создаёт значение даты, после чего `форматДаты` возвращает его в выбранном формате.
