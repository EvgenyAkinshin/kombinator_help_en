# целоеСТекстом

Функция `целоеСТекстом` выводит целое число цифрами и/или прописью и согласует с ним указанное слово.

Например, число `3` и слово `документ` можно вывести как:

```text
3 (три) документа
```

## Синтаксис

```text
целоеСТекстом(число, "слово", "формат", типЧислительного, падеж)
```

**Параметры:**

- `число` — целое число, для которого необходимо сформировать текст;
- `слово` — слово, которое необходимо согласовать с числом;
- `формат` — определяет, как будут отображаться число и слово;
- `типЧислительного` — определяет тип числительного: количественное или порядковое;
- `падеж` — падеж, в котором необходимо вывести числительное и слово.

При необходимости можно указать разделитель тысяч:

```text
целоеСТекстом(
    число,
    "слово",
    "формат",
    типЧислительного,
    падеж,
    "разделительТысяч"
)
```

- `разделительТысяч` — необязательный параметр. Определяет символ, используемый для разделения разрядов числа при цифровой записи.

### Формат

Строка формата определяет состав и порядок результата.

Для неё доступны следующие обозначения:

| Обозначение | Значение |
| --- | --- |
| `i` | число цифрами |
| `ii` | число прописью |
| `W` | слово, согласованное с числом |

Например, если число равно `3`, а слово — `"документ"`:

| Формат | Результат |
| --- | --- |
| `"i W"` | `3 документа` |
| `"ii W"` | `три документа` |
| `"i (ii) W"` | `3 (три) документа` |

Пробелы и знаки препинания в строке формата сохраняются в результате.

Текст, который необходимо вывести без изменений, указывается в одинарных кавычках.

Для параметра `типЧислительного` доступны следующие значения:

- `ТипЧислительного.Количественное` — количественное числительное;
- `ТипЧислительного.Порядковое` — порядковое числительное.

Для параметра `падеж` доступны следующие значения:

| Значение | Вопрос |
| --- | --- |
| `Падеж.Именительный` | кто? что? |
| `Падеж.Родительный` | кого? чего? |
| `Падеж.Дательный` | кому? чему? |
| `Падеж.Винительный` | кого? что? |
| `Падеж.Творительный` | кем? чем? |
| `Падеж.Предложный` | о ком? о чём? |

## Возвращаемое значение

Функция возвращает текстовое значение, сформированное в соответствии с выбранным форматом.

## Особенности

Форма слова определяется автоматически с учётом числа и указанного падежа.

Например, для слова `"документ"` функция выберет подходящую форму:

- `1 документ`;
- `2 документа`;
- `5 документов`.

Разделитель тысяч применяется к цифровой записи числа — `i`.

## Примеры

### Число цифрами и прописью

Если поле `количествоДокументов` содержит:

```text
3
```

выражение:

```text
целоеСТекстом(
    количествоДокументов,
    "документ",
    "i (ii) W",
    ТипЧислительного.Количественное,
    Падеж.Именительный
)
```

вернёт:

```text
3 (три) документа
```

### Число только прописью

Если поле `количествоДокументов` содержит:

```text
5
```

выражение:

```text
целоеСТекстом(
    количествоДокументов,
    "документ",
    "ii W",
    ТипЧислительного.Количественное,
    Падеж.Именительный
)
```

вернёт:

```text
пять документов
```

### Склонение по падежу

Если поле `количествоДокументов` содержит:

```text
3
```

выражение:

```text
целоеСТекстом(
    количествоДокументов,
    "документ",
    "i (ii) W",
    ТипЧислительного.Количественное,
    Падеж.Родительный
)
```

вернёт:

```text
3 (трёх) документов
```

### Разделитель тысяч

Если поле `количествоДокументов` содержит:

```text
1250
```

выражение:

```text
целоеСТекстом(
    количествоДокументов,
    "документ",
    "i W",
    ТипЧислительного.Количественное,
    Падеж.Именительный,
    " "
)
```

вернёт:

```text
1 250 документов
```
