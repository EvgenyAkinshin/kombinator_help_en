# форматДатыПоМаске

Функция `форматДатыПоМаске` выводит дату и время по заданной маске.

В отличие от функции `форматДаты`, здесь формат результата можно настроить самостоятельно.

## Синтаксис

```text
форматДатыПоМаске(дата, маска, [локаль])
```

**Параметры:**

- `дата` — значение даты, времени или даты и времени, которое необходимо отформатировать;
- `маска` — готовый формат или маска, определяющая вид результата;
- `локаль` — язык названий месяцев и дней недели. Необязательный параметр. Если он не указан, используется локаль шаблона.

Для составления маски используются следующие обозначения:

| Обозначение | Значение | Пример |
| --- | --- | --- |
| `dd` | день месяца | `05` |
| `ddd` | сокращённое название дня недели | `сб` |
| `dddd` | полное название дня недели | `суббота` |
| `MM` | месяц числом | `09` |
| `MMM` | сокращённое название месяца | `сен` |
| `MMMM` | полное название месяца | `сентябрь` |
| `yy` | год двумя цифрами | `26` |
| `yyyy` | год четырьмя цифрами | `2026` |
| `HH` | часы | `14` |
| `mm` | минуты | `30` |
| `ss` | секунды | `25` |

Обозначения можно комбинировать и разделять необходимыми символами.

Например:

```text
"dd.MM.yyyy"
```

```text
"yyyy-MM-dd"
```

```text
"dd MMMM yyyy HH:mm"
```

Регистр символов имеет значение:

- `MM` — месяц;
- `mm` — минуты.

Текст, который необходимо вывести без изменений, указывается в одинарных кавычках:

```text
"dd.MM.yyyy 'в' HH:mm"
```

## Возвращаемое значение

Функция возвращает текстовое значение, сформированное по указанной маске.

Например, если поле `датаДоговора` содержит:

```text
05.09.2026
```

выражение:

```text
форматДатыПоМаске(
    датаДоговора,
    "yyyy-MM-dd"
)
```

вернёт:

```text
2026-09-05
```

## Особенности

Локаль влияет на названия месяцев и дней недели.

Например, для маски:

```text
"dd MMMM yyyy"
```

при русской локали результат может выглядеть так:

```text
05 сентября 2026
```

при английской:

```text
05 September 2026
```

## Примеры

### Дата и время

Если поле `датаВремя` содержит:

```text
05.09.2026 14:30:25
```

выражение:

```text
форматДатыПоМаске(
    датаВремя,
    "dd.MM.yyyy HH:mm:ss"
)
```

вернёт:

```text
05.09.2026 14:30:25
```

### Добавление текста

Выражение:

```text
форматДатыПоМаске(
    датаВремя,
    "'Сформировано' dd.MM.yyyy 'в' HH:mm"
)
```

вернёт:

```text
Сформировано 05.09.2026 в 14:30
```

### День недели и дата

Выражение:

```text
форматДатыПоМаске(
    датаВремя,
    "dddd, dd MMMM yyyy"
)
```

вернёт:

```text
суббота, 05 сентября 2026
```

## Связь с другими функциями

В параметр `дата` можно передавать результат функции, возвращающей дату или время.

Например:

```text
форматДатыПоМаске(
    дата(5, 9, 2026),
    "dd MMMM yyyy"
)
```

вернёт:

```text
05 сентября 2026
```
