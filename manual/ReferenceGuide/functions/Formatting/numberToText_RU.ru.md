# числоСТекстом

Функция `числоСТекстом` выводит число вместе с согласованным с ним словом.

## Синтаксис

```text
числоСТекстом(число, "слово", формат, типЧислительного, падеж)
```

**Параметры:**

- `число` — целое или десятичное числовое значение;
- `слово` — слово, которое необходимо согласовать с числом;
- `формат` — определяет способ отображения числа;
- `типЧислительного` — определяет тип числительного;
- `падеж` — падеж, в котором необходимо вывести числительное и слово.

Для параметра `формат` доступны следующие значения:

| Значение | Результат |
| --- | --- |
| `ФорматЭлемента.Длинный` | `5 (пять) комнат` |
| `ФорматЭлемента.Короткий` | `5 комнат` |
| `ФорматЭлемента.Прописью` | `пять комнат` |

Для параметра `типЧислительного` доступны следующие значения:

- `ТипЧислительного.Количественное` — количественное числительное;
- `ТипЧислительного.Порядковое` — порядковое числительное.

Для параметра `падеж` доступны следующие значения:

| Значение | Вопрос |
| --- | --- |
| `Падеж.Именительный` | кто? что? |
| `Падеж.Родительный` | кого? чего? |
| `Падеж.Дательный` | кому? чему? |
| `Падеж.Винительный` | кого? что? |
| `Падеж.Творительный` | кем? чем? |
| `Падеж.Предложный` | о ком? о чём? |

## Возвращаемое значение

Функция возвращает текстовое значение, в котором число и указанное слово согласованы в соответствии с выбранными параметрами.

## Особенности

Функция поддерживает как целые, так и десятичные числа.

Форма слова определяется автоматически с учётом числового значения и указанного падежа.

В отличие от функции `целоеСТекстом`, формат результата выбирается из готовых значений `ФорматЭлемента`.

## Примеры

### Число цифрами и прописью

Если поле `количество` содержит:

```text
5
```

выражение:

```text
числоСТекстом(
    количество,
    "комната",
    ФорматЭлемента.Длинный,
    ТипЧислительного.Количественное,
    Падеж.Именительный
)
```

вернёт:

```text
5 (пять) комнат
```

### Короткий формат

Если поле `количество` содержит:

```text
2
```

выражение:

```text
числоСТекстом(
    количество,
    "документ",
    ФорматЭлемента.Короткий,
    ТипЧислительного.Количественное,
    Падеж.Именительный
)
```

вернёт:

```text
2 документа
```

### Число прописью

Если поле `количество` содержит:

```text
3
```

выражение:

```text
числоСТекстом(
    количество,
    "этаж",
    ФорматЭлемента.Прописью,
    ТипЧислительного.Количественное,
    Падеж.Именительный
)
```

вернёт:

```text
три этажа
```
