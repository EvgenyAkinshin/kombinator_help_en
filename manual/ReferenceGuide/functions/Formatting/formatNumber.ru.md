# форматЧисла

Функция `форматЧисла` изменяет формат отображения числового значения.

С её помощью можно задать количество знаков после запятой, разделитель дробной части и при необходимости разделитель тысяч.

## Синтаксис

```text
форматЧисла(число, "формат", "разделительДробнойЧасти")
```

**Параметры:**

- `число` — числовое значение, которое необходимо отформатировать;
- `формат` — определяет способ отображения числа;
- `разделительДробнойЧасти` — символ, который используется для отделения дробной части от целой.

При необходимости можно указать разделитель тысяч:

```text
форматЧисла(число, "формат", "разделительДробнойЧасти", "разделительТысяч")
```

- `разделительТысяч` — необязательный параметр. Определяет символ, который используется для разделения разрядов целой части числа.

В окне настройки функции формат можно задать двумя способами:

- если **«Свой формат»** выключен — указать количество знаков после запятой;
- если **«Свой формат»** включён — самостоятельно задать строку формата.

### Свой формат

При включённом параметре **«Свой формат»** строка формата составляется с помощью специальных символов:

| **Символ** | **Назначение** |
| :--- | :--- |
| `#` | Разряд числа. Отображает только значимые разряды. |
| `0` | Разряд числа с подстановкой `0`. Если в числе цифры на этом месте нет, подставляется `0`. |
| `.` | Положение разделителя дробной части. Может присутствовать в строке формата только один раз. |
| `,` | Положение разделителя тысяч. |

## Возвращаемое значение

Функция возвращает отформатированное числовое значение в виде текста.

## Особенности

Символы `.` и `,` в строке формата определяют положение разделителей. Символы, которые будут отображаться в результате, задаются параметрами `разделительДробнойЧасти` и `разделительТысяч`.

Если задано меньше знаков после разделителя дробной части, чем содержит исходное число, отображаемое значение округляется.

Поскольку функция возвращает текст, вычисления с числом следует выполнять до применения `форматЧисла`.

## Примеры

### Два знака после запятой

Если поле `число` содержит:

```text
125,6
```

выражение:

```text
форматЧисла(
    число,
    "0.00",
    ","
)
```

вернёт:

```text
125,60
```

### Разделение тысяч

Если поле `число` содержит:

```text
1234567,865464
```

выражение:

```text
форматЧисла(
    число,
    "#,##0.00",
    ",",
    " "
)
```

вернёт:

```text
1 234 567,87
```

### Отображение только значимых разрядов

Если поле `число` содержит:

```text
125,5
```

выражение:

```text
форматЧисла(
    число,
    "0.##",
    ","
)
```

вернёт:

```text
125,5
```

Если поле содержит:

```text
125
```

то же выражение вернёт:

```text
125
```
