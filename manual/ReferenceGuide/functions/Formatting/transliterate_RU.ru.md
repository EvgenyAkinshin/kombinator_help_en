# Транслит

Функция `транслит` преобразует текст с кириллицы в латиницу.

## Синтаксис

```text
транслит(текст)
```

**Параметры:**

- `текст` — текстовое значение, которое необходимо преобразовать в латиницу.

## Возвращаемое значение

Функция возвращает текстовое значение, в котором кириллические буквы заменены соответствующими латинскими символами.

## Особенности

Транслитерация выполняется побуквенно. Регистр исходного текста сохраняется.

Например:

| Кириллица | Латиница |
| --- | --- |
| `Ж` | `Zh` |
| `Ю` | `Iu` |
| `Я` | `Ia` |
| `Й` | `I` |

## Примеры

### Транслитерация ФИО

Если поле `фио` содержит:

```text
Петрова Ирина Сергеевна
```

выражение:

```text
транслит(фио)
```

вернёт:

```text
Petrova Irina Sergeevna
```

## Связь с другими функциями

Функцию `транслит` можно передавать в функции, работающие с текстом.

Например, чтобы одновременно выполнить транслитерацию и привести результат к строчным буквам:

```text
строчн(транслит(фио))
```

Если поле `фио` содержит:

```text
Петрова Ирина Сергеевна
```

результат:

```text
petrova irina sergeevna
```
