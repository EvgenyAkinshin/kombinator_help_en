# форматФИО

Функция `форматФИО` позволяет вывести ФИО в нужном формате и падеже.

## Синтаксис

```text
форматФИО(фио, падеж, формат)
```

**Параметры:**

- `фио` — текстовое значение, содержащее ФИО;
- `падеж` — падеж, в котором необходимо вывести ФИО;
- `формат` — формат отображения ФИО.

Для параметра `падеж` доступны следующие значения:

- `Падеж.Именительный` — кто? что?
- `Падеж.Родительный` — кого? чего?
- `Падеж.Дательный` — кому? чему?
- `Падеж.Винительный` — кого? что?
- `Падеж.Творительный` — кем? чем?
- `Падеж.Предложный` — о ком? о чём?

Для параметра `формат` доступны следующие значения:

| Значение | Результат |
| --- | --- |
| `ФорматФИО.ФамилияИмяОтчество` | Иванов Иван Иванович |
| `ФорматФИО.ФамилияИмя` | Иванов Иван |
| `ФорматФИО.ИмяОтчество` | Иван Иванович |
| `ФорматФИО.ФамилияИО` | Иванов И.И. |
| `ФорматФИО.ИОФамилия` | И.И. Иванов |
| `ФорматФИО.Фамилия` | Иванов |
| `ФорматФИО.Имя` | Иван |
| `ФорматФИО.Отчество` | Иванович |

## Возвращаемое значение

Функция возвращает текстовое значение с ФИО в выбранном формате.

Например, если `фио` содержит:

```text
Иванов Иван Иванович
```

выражение:

```text
форматФИО(фио, Падеж.Именительный, ФорматФИО.ФамилияИО)
```

вернёт:

```text
Иванов И.И.
```

## Особенности

При указании падежа функция склоняет части ФИО, которые входят в выбранный формат.

Если ФИО склоняется некорректно, в режиме заполнения шаблона нужную форму можно задать с помощью грамматических исключений.

## Примеры

### Инициалы перед фамилией

```text
форматФИО(фио, Падеж.Именительный, ФорматФИО.ИОФамилия)
```

Результат:

```text
И.И. Иванов
```

### Фамилия в дательном падеже

```text
форматФИО(фио, Падеж.Дательный, ФорматФИО.Фамилия)
```

Результат:

```text
Иванову
```

### Имя и отчество в родительном падеже

```text
форматФИО(фио, Падеж.Родительный, ФорматФИО.ИмяОтчество)
```

Результат:

```text
Ивана Ивановича
```

## Ошибки

Все три параметра функции являются обязательными.

Например, в выражении:

```text
форматФИО(фио, Падеж.Именительный)
```

не указан параметр `формат`, поэтому при вычислении возникнет ошибка.

Также необходимо использовать допустимые значения для параметров `падеж` и `формат`.

## Связь с другими функциями

Результат функции `форматФИО` можно передавать в функции, работающие с текстом.

Например, функция `прописн` позволяет вывести результат прописными буквами:

```text
прописн(форматФИО(фио, Падеж.Именительный, ФорматФИО.ФамилияИО))
```

Результат:

```text
ИВАНОВ И.И.
```
