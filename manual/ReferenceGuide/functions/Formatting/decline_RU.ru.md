# Склонение

Функция `склонение` изменяет падеж и число слова или словосочетания.

## Синтаксис

```text
склонение(текст, падеж, число)
```

**Параметры:**

- `текст` — текстовое значение, которое необходимо склонить;
- `падеж` — падеж, в котором необходимо вывести текст;
- `число` — число, в котором необходимо вывести текст.

Для параметра `падеж` доступны следующие значения:

| Значение | Вопрос |
| --- | --- |
| `Падеж.Именительный` | кто? что? |
| `Падеж.Родительный` | кого? чего? |
| `Падеж.Дательный` | кому? чему? |
| `Падеж.Винительный` | кого? что? |
| `Падеж.Творительный` | кем? чем? |
| `Падеж.Предложный` | о ком? о чём? |

Для параметра `число` доступны следующие значения:

- `Единственное`;
- `Множественное`.

## Возвращаемое значение

Функция возвращает текстовое значение в указанном падеже и числе.

## Особенности

Функция `склонение` не предназначена для работы с ФИО. Для склонения ФИО используйте функцию `инициалы`.

## Примеры

### Склонение должности

Если поле `должность` содержит:

```text
Генеральный директор
```

выражение:

```text
склонение(должность, Падеж.Родительный, Единственное)
```

вернёт:

```text
Генерального директора
```

### Склонение словосочетания

Если поле `наименование` содержит:

```text
договор поставки
```

выражение:

```text
склонение(наименование, Падеж.Творительный, Единственное)
```

вернёт:

```text
договором поставки
```

### Изменение числа

Если поле `наименование` содержит:

```text
ответственное лицо
```

выражение:

```text
склонение(наименование, Падеж.Именительный, Множественное)
```

вернёт:

```text
ответственные лица
```

## Ошибки

Если исходный текст содержит числа, специальные символы или знаки препинания, функция может не обработать значение и вернуть ошибку.

Например:

```text
2 юриста, 1 бухгалтер
```

Количество и склоняемый текст рекомендуется хранить в отдельных полях.
