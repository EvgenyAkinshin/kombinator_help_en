# **склонение**

Функция `склонение` предназначена для изменения формы отдельных слов или целых фраз в зависимости от заданного падежа и числа.

📌 **Важно:** не применяется для **ФИО**

## **Синтаксис**

```
склонение(текст, падеж, число)
```
**Где:**

* `текст` — переменная (идентификатор поля), к которой применяется склонение;

* `падеж` — форма слова: `Именительный`, `Родительный`, `Дательный`, `Винительный`, `Творительный`, `Предложный`;

* `число` — `Единственное` или `Множественное`.

## **Принцип работы**

1. **Функция получает текст из поля**, которое вы указали в первом аргументе.

2. **Применяет нужный падеж и число** — согласно выбранным параметрам (например, Родительный, Множественное).

3. **Возвращает изменённую форму слова или фразы**, уже в нужной грамматической конструкции.

⚠️ **Важно**

Если в значение поля переданы **числа, спецсимволы или знаки препинания** (например: `2 юриста, 1 бухгалтер`), функция **может не отработать** и вернуть **ошибку обработки**.

Чтобы избежать этого:

* уберите числа и лишние знаки из значения;

* либо используйте отдельные поля: одно — для количества, другое — для текста.

## **Пример:**

**Задача:** автоматически склонять название должности в тексте (Р.П.).

**Шаги:**

1. Вставьте текстовое поле в шаблон.

2. Нажмите дважды левой кнопкой мыши на вставленное поле в теле шаблона.

3. Нажмите на кнопку `f(X)` и выберите **«Морфологические»** → **«Склонение»**.

4. Укажите параметры:

    * Падеж: `Родительный`

    * Число: `Единственное`
