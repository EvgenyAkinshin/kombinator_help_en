# начинаетсяС

Функция **`начинаетсяС`** проверяет, начинается ли строка с указанной подстроки. Она подходит для условий, когда дальнейшее формирование документа зависит от начала текстового значения.

## Синтаксис

```text
начинаетсяС(Строка, Подстрока, Учитывать регистр)
```

- **`Строка`** — обязательный параметр. Исходная строка, начало которой необходимо проверить.
- **`Подстрока`** — обязательный параметр. Последовательность символов, с которой должна начинаться строка.
- **`Учитывать регистр`** — необязательный логический параметр. Определяет, учитывать ли различия между прописными и строчными буквами.

Если параметр **`Учитывать регистр`** не указан, регистр учитывается.

Чтобы выполнить проверку без учёта регистра, передайте в третьем параметре `ложь`.

## Возвращаемое значение

Функция возвращает логическое значение:

- `True` — строка начинается с указанной подстроки;
- `False` — строка не начинается с указанной подстроки.

Полученное значение можно использовать в условиях и других выражениях.

## Особенности

Если **`Подстрока`** пустая, функция возвращает `True`.

## Пример

Допустим, поле **`Наименование товара`** содержит значение:

```text
Монтажный комплект для оборудования
```

Необходимо проверить, начинается ли значение поля со слова `МОНТАЖНЫЙ`, не учитывая регистр:

```text
начинаетсяС(НаименованиеТовара, "МОНТАЖНЫЙ", ложь)
```

Результат:

```text
True
```

Поскольку в третьем параметре указано `ложь`, различие регистра не влияет на результат.
