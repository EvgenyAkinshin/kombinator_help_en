# заканчиваетсяНа

Функция **`заканчиваетсяНа`** проверяет, заканчивается ли строка указанной подстрокой. Она подходит для условий, когда дальнейшее формирование документа зависит от окончания текстового значения.

## Синтаксис

```text
заканчиваетсяНа(Строка, Подстрока, Учитывать регистр)
```

- **`Строка`** — обязательный параметр. Исходная строка, окончание которой необходимо проверить.
- **`Подстрока`** — обязательный параметр. Последовательность символов, с которой должно совпадать окончание строки.
- **`Учитывать регистр`** — необязательный логический параметр. Определяет, учитывать ли различия между прописными и строчными буквами.

Если параметр **`Учитывать регистр`** не указан, регистр учитывается.

Чтобы выполнить проверку без учёта регистра, передайте в третьем параметре `ложь`.

## Возвращаемое значение

Функция возвращает логическое значение:

- `True` — строка заканчивается указанной подстрокой;
- `False` — строка не заканчивается указанной подстрокой.

Полученное значение можно использовать в условиях и других выражениях.

## Особенности

Если **`Подстрока`** пустая, функция возвращает `True`.

## Пример

Необходимо проверить, заканчивается ли значение словом `ПОСТАВКИ`, не учитывая регистр:

```text
заканчиваетсяНа("Договор поставки", "ПОСТАВКИ", ложь)
```

Результат:

```text
True
```

Поскольку в третьем параметре указано `ложь`, различие регистра не влияет на результат.
