# деньнед

Функция `деньнед` определяет день недели для указанной даты и возвращает его номер.

Функция пригодится, когда необходимо определить день недели и использовать полученное значение в условиях или других выражениях.

## Синтаксис

```text
деньнед(дата, [формат_возврата])
```

**Параметры:**

- `дата` — дата, для которой необходимо определить день недели. Обязательный параметр;
- `формат_возврата` — код, определяющий первый день недели и способ нумерации дней. Необязательный параметр.

В качестве параметра `дата` можно использовать:

- значение поля с датой;
- значение поля с датой и временем;
- текстовое значение, содержащее корректную дату;
- результат другой функции, возвращающей дату;
- выражение, результатом которого является дата.

Наличие времени не влияет на определение дня недели.

## Возвращаемое значение

Функция возвращает номер дня недели.

Если `формат_возврата` не указан, используется следующая нумерация:

```text
Понедельник — 1
Вторник — 2
Среда — 3
Четверг — 4
Пятница — 5
Суббота — 6
Воскресенье — 7
```

Например:

```text
деньнед("03.09.2026")
```

Результат:

```text
4
```

поскольку 3 сентября 2026 года — четверг.

## Нумерация дней недели

Параметр `формат_возврата` позволяет изменить первый день недели и используемую нумерацию.

| Формат | Первый день недели | Нумерация |
| --- | --- | --- |
| `1` | понедельник | `0–6` |
| `2` | вторник | `0–6` |
| `3` | среда | `0–6` |
| `4` | четверг | `0–6` |
| `5` | пятница | `0–6` |
| `6` | суббота | `0–6` |
| `7` | воскресенье | `0–6` |
| `11` | понедельник | `1–7` |
| `12` | вторник | `1–7` |
| `13` | среда | `1–7` |
| `14` | четверг | `1–7` |
| `15` | пятница | `1–7` |
| `16` | суббота | `1–7` |
| `17` | воскресенье | `1–7` |

Формат `11` соответствует нумерации по умолчанию.

Например:

```text
деньнед("03.09.2026", 1)
```

Результат:

```text
3
```

При формате `1` понедельник имеет номер `0`, поэтому четверг получает номер `3`.

Если использовать формат `12`:

```text
деньнед("03.09.2026", 12)
```

результат также будет:

```text
3
```

В этом случае первым днём недели считается вторник, которому присваивается номер `1`.

## Примеры

**Определение выходного дня**

Если поле `дата` содержит:

```text
05.09.2026
```

то выражение:

```text
деньнед(дата)
```

вернёт:

```text
6
```

При нумерации по умолчанию значения `6` и `7` соответствуют субботе и воскресенью. Поэтому, например, принадлежность даты к выходным можно проверить выражением:

```text
деньнед(дата) >= 6
```

## Ошибки

Функция возвращает ошибку, если:

- обязательный параметр не содержит значения;
- переданное значение не может быть обработано как корректная дата;
- в `формат_возврата` указано значение, отличное от `1–7` и `11–17`.

Например, ошибку вернут значения формата `8`, `10` или `18`.

## Связь с другими функциями

В функцию `деньнед` можно передавать дату, полученную с помощью другой функции.

Например:

```text
деньнед(тдата())
```

выражение вернёт номер текущего дня недели.

Функцию также можно использовать с функциями изменения даты. Например:

```text
деньнед(смещдат(исходнаяДата, 1))
```

Сначала `смещдат` рассчитывает дату следующего дня, после чего `деньнед` определяет номер соответствующего дня недели.
