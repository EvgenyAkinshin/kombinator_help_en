# тдата

Функция `тдата` возвращает текущие дату и время на момент формирования документа.

Функция пригодится, когда необходимо автоматически подставить точные дату и время формирования или использовать их в вычислениях.

## Синтаксис

```text
тдата()
```

**Параметры:**

Функция не принимает параметров.

## Возвращаемое значение

Функция возвращает текущие дату и время.

Например:

```text
тдата()
```

Результат:

```text
02.09.2026 13:45:30
```

## Особенности

Значение функции определяется в момент формирования документа.

В отличие от функции `сегодня`, которая возвращает текущую дату со временем `00:00:00`, функция `тдата` возвращает актуальные дату и время.

Например:

```text
сегодня()
```

Результат:

```text
02.09.2026 00:00:00
```

```text
тдата()
```

Результат:

```text
02.09.2026 13:45:30
```

## Примеры

**Смещение даты и времени**

```text
смещдат(тдата(), 1)
```

Если `тдата()` возвращает:

```text
02.09.2026 13:45:30
```

результат:

```text
03.09.2026 13:45:30
```

---

**Смещение на месяц**

```text
датамес(тдата(), 1)
```

Если `тдата()` возвращает:

```text
02.09.2026 13:45:30
```

результат:

```text
02.10.2026 13:45:30
```

## Связь с другими функциями

Результат `тдата` можно использовать в других функциях для работы с датами и временем.

Например, вывести только дату в стандартном формате:

```text
форматДаты(
    тдата(),
    ФорматДаты.ДатаКратко
)
```

Результат:

```text
02.09.2026
```

Для собственного формата даты и времени можно использовать функцию `форматДатыПоМаске`:

```text
форматДатыПоМаске(
    тдата(),
    "'Сформировано' dd.MM.yyyy 'в' HH:mm"
)
```

Результат:

```text
Сформировано 02.09.2026 в 13:45
```
