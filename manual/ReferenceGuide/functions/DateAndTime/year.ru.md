# год

Функция `год` возвращает год из указанной даты.

Функция пригодится, когда год необходимо получить отдельно от полного значения даты и использовать в документе или выражении.

## Синтаксис

```text
год(дата)
```

**Параметры:**

- `дата` — дата, из которой необходимо получить год. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой;
- результат другой функции, возвращающей дату;
- выражение, результатом которого является дата.

## Возвращаемое значение

Функция возвращает год в виде числа.

Например:

```text
год("11.08.2026")
```

Результат:

```text
2026
```

## Примеры

**Получение года из значения поля**

Если поле `датаДоговора` содержит:

```text
11.08.2026
```

то выражение:

```text
год(датаДоговора)
```

вернёт:

```text
2026
```

---

**Получение текущего года**

Текущий год можно получить из результата функции `сегодня`:

```text
год(сегодня())
```

Если документ формируется в 2026 году, результат:

```text
2026
```

## Ошибки

Функция возвращает ошибку, если переданное значение не является корректной датой.

Ошибка также возникает, если обязательный параметр не содержит значения.

Например, если поле содержит обычный текст, а не значение даты, получить из него год не получится.

## Связь с другими функциями

Функцию `год` можно использовать совместно с другими функциями для работы с датами.

Например, из существующей даты можно получить её части, изменить год и сформировать новое значение:

```text
дата(
    день(исходнаяДата),
    месяц(исходнаяДата),
    год(исходнаяДата) + 1
)
```

Такое выражение сохраняет день и месяц исходной даты, а значение года увеличивает на `1`.

Год также можно получить из даты, сформированной другой функцией:

```text
год(датамес(исходнаяДата, 6))
```

В этом случае функция `датамес` сначала рассчитывает новую дату, а `год` возвращает год из полученного значения.
