# время

Функция `время` формирует значение времени из отдельно заданных часов, минут и секунд.

Функция пригодится, когда части времени хранятся в разных полях или вычисляются непосредственно в выражении.

## Синтаксис

```text
время(часы, минуты, секунды)
```

**Параметры:**

- `часы` — часы. Обязательный параметр. Числовое значение от `0` до `23`;
- `минуты` — минуты. Обязательный параметр. Числовое значение от `0` до `59`;
- `секунды` — секунды. Обязательный параметр. Числовое значение от `0` до `59`.

Параметры указываются в порядке: **часы, минуты, секунды**.

В качестве параметров можно использовать:

- числа;
- значения числовых полей;
- результаты других функций;
- выражения.

## Возвращаемое значение

Функция возвращает значение времени с заданными часами, минутами и секундами.

В полном представлении результата используется техническая дата `01.01.0001`.

Например:

```text
время(14, 30, 0)
```

Результат:

```text
01.01.0001 14:30:00
```

## Примеры

**Использование значений полей и выражения**

Если:

- `часы` = `13`;
- `минуты` = `30`;
- `секунды` = `0`;

то выражение:

```text
время(часы + 1, минуты, секунды)
```

вернёт:

```text
01.01.0001 14:30:00
```

## Ошибки

Функция возвращает ошибку, если значение одного из параметров выходит за допустимый диапазон.

Например:

```text
время(24, 0, 0)
```

```text
время(23, 60, 0)
```

```text
время(23, 59, 60)
```

Ошибка также возникает, если один из обязательных параметров не содержит значения.

## Связь с другими функциями

Функцию `время` можно использовать совместно с другими функциями для работы с датой и временем.

Например, функции `час`, `минуты` и `секунды` позволяют получить отдельные части текущего времени и сформировать из них новое значение:

```text
время(
    час(тдата()),
    минуты(тдата()),
    секунды(тдата())
)
```

Для вывода времени без технической даты `01.01.0001` можно использовать функцию `форматДатыПоМаске`:

```text
форматДатыПоМаске(
    время(14, 30, 25),
    "HH:mm:ss"
)
```

Результат:

```text
14:30:25
```
