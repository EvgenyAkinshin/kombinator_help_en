# месяц

Функция `месяц` возвращает номер месяца из указанной даты.

Функция пригодится, когда месяц необходимо получить отдельно от полного значения даты и использовать в документе или выражении.

## Синтаксис

```text
месяц(дата)
```

**Параметры:**

- `дата` — дата, из которой необходимо получить номер месяца. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой;
- результат другой функции, возвращающей дату;
- выражение, результатом которого является дата.

## Возвращаемое значение

Функция возвращает номер месяца в виде числа от `1` до `12`.

Например:

```text
месяц("11.08.2026")
```

Результат:

```text
8
```

## Примеры

**Получение месяца из значения поля**

Если поле `датаДоговора` содержит:

```text
11.08.2026
```

то выражение:

```text
месяц(датаДоговора)
```

вернёт:

```text
8
```

---

**Получение текущего месяца**

Текущий месяц можно получить из результата функции `сегодня`:

```text
месяц(сегодня())
```

Если документ формируется в сентябре, результат:

```text
9
```

## Ошибки

Функция возвращает ошибку, если переданное значение не является корректной датой.

Ошибка также возникает, если обязательный параметр не содержит значения.

## Связь с другими функциями

Функцию `месяц` можно использовать совместно с другими функциями для работы с датами.

Например, из существующей даты можно получить её отдельные части и сформировать новое значение:

```text
дата(
    день(исходнаяДата),
    месяц(исходнаяДата),
    год(исходнаяДата) + 1
)
```

Такое выражение сохраняет день и месяц исходной даты, а год увеличивает на `1`.

Номер месяца также можно получить из даты, рассчитанной другой функцией:

```text
месяц(датамес(исходнаяДата, 6))
```

В этом случае функция `датамес` сначала рассчитывает новую дату, а `месяц` возвращает номер месяца из полученного значения.
