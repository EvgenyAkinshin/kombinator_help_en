# датавремя

Функция `датавремя` формирует единое значение даты и времени из отдельно заданных года, месяца, дня, часов, минут и секунд.

Функция пригодится, когда части даты и времени хранятся в разных полях или вычисляются непосредственно в выражении.

## Синтаксис

```text
датавремя(год, месяц, день, часы, минуты, секунды)
```

**Параметры:**

- `год` — год. Обязательный числовой параметр;
- `месяц` — номер месяца. Обязательный числовой параметр. Значение от `1` до `12`;
- `день` — день месяца. Обязательный числовой параметр. Значение от `1` до `31`;
- `часы` — часы. Обязательный числовой параметр. Значение от `0` до `23`;
- `минуты` — минуты. Обязательный числовой параметр. Значение от `0` до `59`;
- `секунды` — секунды. Обязательный числовой параметр. Значение от `0` до `59`.

Параметры указываются в порядке: **год, месяц, день, часы, минуты, секунды**.

В качестве параметров можно использовать:

- числа;
- значения числовых полей;
- результаты других функций;
- выражения.

## Возвращаемое значение

Функция возвращает значение даты и времени.

Например:

```text
датавремя(2026, 8, 11, 14, 30, 15)
```

Результат:

```text
11.08.2026 14:30:15
```

## Особенности

Переданные значения должны образовывать корректные дату и время.

Дробные числовые значения могут быть преобразованы при формировании результата, поэтому для параметров рекомендуется использовать целые числа.

## Примеры

**Использование значений полей и выражения**

Если поля содержат:

- `год` = `2026`;
- `месяц` = `8`;
- `день` = `10`;
- `часы` = `14`;
- `минуты` = `30`;
- `секунды` = `15`;

то выражение:

```text
датавремя(
    год,
    месяц,
    день + 1,
    часы,
    минуты,
    секунды
)
```

вернёт:

```text
11.08.2026 14:30:15
```

## Ошибки

Функция возвращает ошибку, если из переданных значений невозможно сформировать корректные дату и время.

Например:

```text
датавремя(2026, 2, 31, 14, 30, 15)
```

вернёт ошибку, поскольку в феврале 2026 года нет 31-го дня.

Ошибка также возникает, если значение одного из параметров выходит за допустимый диапазон.

## Связь с другими функциями

Функцию `датавремя` можно использовать совместно с функциями, которые получают отдельные части даты и времени.

Например, из значения даты и времени можно получить отдельные компоненты и сформировать новое значение:

```text
датавремя(
    год(тдата()),
    месяц(тдата()),
    день(тдата()),
    час(тдата()),
    минуты(тдата()),
    секунды(тдата())
)
```

Для вывода сформированного значения в собственном формате можно использовать функцию `форматДатыПоМаске`:

```text
форматДатыПоМаске(
    датавремя(2026, 8, 11, 14, 30, 15),
    "dd MMMM yyyy 'в' HH:mm"
)
```

При русской локали результат:

```text
11 августа 2026 в 14:30
```
