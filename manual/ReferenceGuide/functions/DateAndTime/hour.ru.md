# час

Функция `час` возвращает значение часа из даты и времени или значения времени.

Функция пригодится, когда час необходимо получить отдельно и использовать в документе или выражении.

## Синтаксис

```text
час(значение)
```

**Параметры:**

- `значение` — дата и время или время, из которого необходимо получить час. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой и временем или временем;
- текстовое значение с датой и временем или временем в корректном формате;
- результат другой функции;
- выражение, результат которого может быть обработан как дата или время.

Например, функция может обработать:

```text
03.09.2026 15:53:21
```

или:

```text
15:53:21
```

## Возвращаемое значение

Функция возвращает значение часа в виде числа от `0` до `23`.

Например:

```text
час("03.09.2026 15:53:21")
```

Результат:

```text
15
```

## Примеры

**Получение часа из значения времени**

```text
час("15:53:21")
```

Результат:

```text
15
```

---

**Получение часа из значения поля**

Если поле `времяПодписания` содержит:

```text
15:53:21
```

то выражение:

```text
час(времяПодписания)
```

вернёт:

```text
15
```

---

**Получение текущего часа**

```text
час(тдата())
```

Например, если текущее время `15:53:21`, функция вернёт:

```text
15
```

## Ошибки

Функция возвращает ошибку, если переданное значение не может быть обработано как дата или время.

Ошибка также возникает, если:

- обязательный параметр не содержит значения;
- передано обычное числовое значение.

## Связь с другими функциями

Функцию `час` можно использовать совместно с функциями `минуты` и `секунды` для получения отдельных частей времени.

Например:

```text
время(
    час(исходноеВремя),
    минуты(исходноеВремя),
    секунды(исходноеВремя)
)
```

Если `исходноеВремя` содержит:

```text
15:53:21
```

выражение сформирует значение времени с теми же часами, минутами и секундами.
