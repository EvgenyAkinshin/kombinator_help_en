# минуты

Функция `минуты` возвращает значение минут из даты и времени или значения времени.

Функция пригодится, когда минуты необходимо получить отдельно и использовать в документе или выражении.

## Синтаксис

```text
минуты(значение)
```

**Параметры:**

- `значение` — дата и время или время, из которого необходимо получить минуты. Обязательный параметр.

В качестве параметра можно использовать:

- значение поля с датой и временем или временем;
- текстовое значение с датой и временем или временем в корректном формате;
- результат другой функции;
- выражение, результат которого может быть обработан как дата или время.

Например, функция может обработать:

```text
03.09.2026 15:53:21
```

или:

```text
15:53:21
```

## Возвращаемое значение

Функция возвращает значение минут в виде числа от `0` до `59`.

Например:

```text
минуты("03.09.2026 15:53:21")
```

Результат:

```text
53
```

## Примеры

**Получение минут из значения времени**

```text
минуты("15:53:21")
```

Результат:

```text
53
```

---

**Получение минут из значения поля**

Если поле `времяПодписания` содержит:

```text
15:53:21
```

то выражение:

```text
минуты(времяПодписания)
```

вернёт:

```text
53
```

---

**Получение текущего значения минут**

```text
минуты(тдата())
```

Например, если текущее время `15:53:21`, функция вернёт:

```text
53
```

## Ошибки

Функция возвращает ошибку, если переданное значение не может быть обработано как дата или время.

Ошибка также возникает, если:

- обязательный параметр не содержит значения;
- передано обычное числовое значение.

## Связь с другими функциями

Функцию `минуты` можно использовать совместно с функциями `час` и `секунды` для получения отдельных частей времени.

Например:

```text
время(
    час(исходноеВремя),
    минуты(исходноеВремя),
    секунды(исходноеВремя)
)
```

Если `исходноеВремя` содержит:

```text
15:53:21
```

выражение сформирует значение времени с теми же часами, минутами и секундами.
