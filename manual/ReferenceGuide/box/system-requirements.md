Сервер Комбинатор поставляется в виде образа **Docker**. Перед развёртыванием на конечной машине необходимо установить **Docker Engine** (или **Docker Desktop**, если планируется использование графической оболочки для управления образами). 

Рекомендуемая операционная система – **Ubuntu 20.04LTS** или более новая.

**Минимальные системные требования к аппаратному обеспечению:**

1. **Оперативная память:** 2 ГБ.
2. **Процессор:** 2 ядра.
3. **Диск:** 1,5 ГБ свободного места.
4. **Диск для развёртывания образа PostgreSQL (дополнительно):** 450 МБ свободного места.
