# Поле «Дата»

Поле **«Дата»** используется для хранения календарной даты. Значение поля можно выводить в разных форматах и обрабатывать с помощью функций.

Подходит, например, для даты заключения договора, даты рождения, даты оплаты, даты начала или окончания периода.

## Создание и добавление поля

Создание и добавление полей: [ИНСТРУКЦИЯ](../Bitrix/creat.md)

## Значение поля

Поле содержит календарную дату без времени.

При добавлении поля в шаблон через анкету можно выбрать формат, в котором его значение должно отображаться в сформированном документе. Поэтому одно и то же значение поля может быть выведено в разных форматах.

При необходимости из значения можно отдельно получить [год](../functions/Date and time/year.md), [месяц](../functions/Date and time/month.md), [день](../functions/Date and time/day.md), [день недели](../functions/Date and time/weekday.md) или [номер недели](../functions/Date and time/weeknum.md) с помощью соответствующих функций.

## Вставка поля через вкладку «Метки»

Значение поля **«Дата»** можно вставить в шаблон через метку [«Значение»](../directives/expression.md).

В свойстве **«Выражение»** указывается поле, значение которого необходимо вывести.

Например:

```text
сделки.датаДоговора
```

Здесь:

- `сделки` — сущность Битрикс24, из которой берутся данные;
- `датаДоговора` — поле, содержащее дату.

При формировании документа метка будет заменена значением этого поля.

В метке **«Значение»** можно использовать функции для обработки и форматирования даты.

Например:

```text
форматДаты(сделки.датаДоговора, ФорматДаты.ДатаКратко)
```

В этом случае дата будет выведена в формате, заданном функцией.

## Функции для работы с полем

Для поля **«Дата»** доступны функции для получения отдельных частей даты, её изменения и форматирования.

### Получение частей даты

- [год](../functions/Date and time/year.md) — возвращает год;
- [месяц](../functions/Date and time/month.md) — возвращает номер месяца;
- [день](../functions/Date and time/day.md) — возвращает день месяца;
- [деньнед](../functions/Date and time/weekday.md) — возвращает номер дня недели;
- [номнедели](../functions/Date and time/weeknum.md) — возвращает номер недели.

### Изменение даты

- [датамес](../functions/Date and time/edate.md) — смещает дату на указанное количество месяцев;
- [смещдат](../functions/Date and time/dateshift.md) — смещает дату на указанное количество дней;
- [начмесяца](../functions/Date and time/bomonth.md) — возвращает дату первого дня месяца;
- [конмесяца](../functions/Date and time/eomonth.md) — возвращает дату последнего дня месяца;
- [разндат](../functions/Date and time/datediff.md) — вычисляет разницу между датами.

### Форматирование

- [форматДаты](../functions/Formatting/formatDate_RU.md) — изменяет формат отображения даты.
