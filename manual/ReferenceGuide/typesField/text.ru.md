# Поле «Текст»

Поле **«Текст»** используется для хранения текстовых значений: ФИО, должностей, адресов, номеров телефонов, реквизитов, номеров договоров и другой информации.

В поле можно передавать буквы, цифры, пробелы, знаки препинания и другие символы.

## Создание и добавление поля

Создание и добавление полей: [ИНСТРУКЦИЯ](../Bitrix/creat.md)

## Значение поля

Поле содержит текстовое значение.

Например:

```text
Иванов Иван Иванович
```

```text
г. Москва, ул. Тверская, д. 10
```

```text
Договор № 125/2026
```

Поле также подходит для значений, состоящих из цифр, если они не используются в математических расчётах. Например:

- ИНН;
- БИК;
- ОГРН;
- расчётный счёт;
- номер телефона;
- номер договора;
- серийный номер.

## Вставка поля через вкладку «Метки»

Значение текстового поля можно вставить в шаблон через метку [«Значение»](../directives/expression.md).

1. Установите курсор в нужное место шаблона.
2. Перейдите на вкладку **«Метки»** и выберите **«Значение»**.
3. В поле **«Выражение»** укажите идентификатор текстового поля.
4. Нажмите **«ОК»**.

> При формировании документа метка будет заменена значением указанного поля.

## Функции для работы с полем

Значение текстового поля можно использовать в функциях для изменения, поиска и обработки текста.

### Текстовые функции

- [длина](../functions/Text/length.md) — возвращает количество символов в строке;
- [обрезатьпробелы](../functions/Text/trim.md) — удаляет пробелы в начале и конце строки;
- [прописн](../functions/Text/upper.md) — переводит текст в верхний регистр;
- [строчн](../functions/Text/lower.md) — переводит текст в нижний регистр;
- [пропнач](../functions/Text/proper.md) — делает первую букву каждого слова заглавной;
- [пстр](../functions/Text/mid.md) — возвращает часть строки;
- [поиск](../functions/Text/find.md) — находит указанный фрагмент в строке;
- [подставить](../functions/Text/substitute.md) — заменяет указанный текст или символы;
- [повтор](../functions/Text/repeat.md) — повторяет строку заданное количество раз;
- [содержит](../functions/Text/contains.md) — ;
- [заканчиваетсяНа](../functions/Text/endsWith.md) — ;
- [начинаетсяС](../functions/Text/startsWith.md) — .

### Морфологические функции

Для некоторых текстовых значений можно использовать морфологические функции:

- [форматФИО](../functions/Formatting/formatFullName_RU.md) — изменяет формат ФИО и его падеж;
- [окончание](../functions/Formatting/wordEnding_RU.md) — подставляет окончание в зависимости от рода и числа;
- [склонение](../functions/Formatting/decline_RU.md) — изменяет форму слова или фразы по падежу и числу;
- [транслит](../functions/Formatting/transliterate_RU.md) — преобразует текст с кириллицы в латиницу.

> Некоторые морфологические функции предназначены для определённого содержимого поля. Например, функция `форматФИО` используется для текста, содержащего ФИО.
