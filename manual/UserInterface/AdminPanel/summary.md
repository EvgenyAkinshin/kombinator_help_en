# Основная информация

В данном разделе отображается **основная информация об организации**.

**Функционал включает:**

1. **Общая информация об организации**

     * Наименование организации.
     * Дополнительная информация (можно вписать комментарии или описание).
     * Дата создания организации.
     * Статистика по документам и шаблонам (количество активных и удалённых шаблонов, число созданных документов)

2. **Сведения о лицензии**

     * Количество лицензий, закреплённых за организацией.
     * Количество пользователей, использующих систему.
     * Дата окончания действия лицензии
     * Возможность перейти к подробной информации по лицензии

3. **Администраторы организации**
     * Список администраторов с их логинами и наименованиями
     * Возможность просмотреть подробности по каждому администратору

Этот раздел служит для **централизованного управления организацией**, проверки её текущего состояния, мониторинга лицензий и контроля доступа администраторов.
