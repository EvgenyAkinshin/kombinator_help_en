# Редактирование записей в справочнике

1. Перейдите в раздел **«Справочники»**.

2. В списке справочников кликните **левой кнопкой мыши** на нужный справочник.

3. В открывшемся справочнике найдите запись, которую необходимо изменить.

4. Откройте запись одним из способов:

    * кликните по строке с записью;
  
    * или нажмите **правой кнопкой мыши** и выберите пункт **«Редактировать»**.

5. Внесите изменения в поля.

6. Нажмите кнопку **«ОК»**.
