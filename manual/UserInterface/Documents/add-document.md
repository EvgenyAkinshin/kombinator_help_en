# Generating a document

Generate the final document from a Bitrix24 CRM item. This allows you to check how the template works with actual CRM data.

## Preparing the CRM item

1. Open the CRM item for which the template has been configured, for example a **deal**.

2. Check that the fields whose data should be added to the document are filled in.

3. If needed, add or correct the data in the CRM item.

## Generating the document

1. In the action panel above the timeline, click **«New document»**.

      If the button is not displayed in the main panel, open **«More»**.

2. Select **«New document»**.

3. Select the prepared template.

4. Wait for the data from the CRM item to load into the template.

5. Click **«Done»** in the upper-right corner.

6. Enter the document name and click **«OK»**.

The generated document will appear in the CRM item timeline.

## Checking the result

Open the generated document and check:

- whether the data from the CRM item was inserted correctly;
- whether conditions and selected options worked as expected;
- whether tables and calculations were generated correctly;
- whether the document formatting was preserved.

If the issue is caused by the data, correct it in the CRM item and generate the document again.

If the issue is related to the template logic or formatting, return to the template editor, make the required changes, and repeat the check.
